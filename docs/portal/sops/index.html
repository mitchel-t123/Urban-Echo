How To Do Payroll
Weekly payroll via QuickBooks, Rentman & NAB  ·  Admin only
▾
0 / 0
QuickBooks — Set Up Pay Run
✓
Open QuickBooks
✓
Press "All Apps" → "Payroll" → "Employees"
✓
Press "New Pay Run"
✓
Set pay schedule to "Weekly Employees"
✓
Select "Manually add payees to this pay run", "Create Pay Run With Empty Pays" and "Include terminated employees" then press "Create"
Rentman — Check Hours
✓
Open Rentman
✓
Press "Time Registration" → "Time Registration"
✓
Press "Views" → "Grouped by crew member and type"
✓
Set the time registration period to the previous week (Monday to Sunday)
✓
Make note of all employees who registered hours for that period
QuickBooks — Enter Hours & Finalise
✓
In QuickBooks press "Pay Run Actions" → "Add Payees"
✓
Add everyone who registered hours for the relevant period
✓
Press the dropdown arrow next to a person's name → "Actions" → "Add Earnings"
✓
Insert hours worked (total from "Registered Time" column in Rentman) then press "Save"
✓
Collapse the person's row then repeat for every other payee
✓
Press "Finalise Pay Run" → "Finalise" in the popup
✓
Press "Lodge With ATO" → tick the box → "Lodge pay event" → "Close"
✓
Press "Go to Pay Run" → "Create Super Payment" → "Submit" → "Submit" in the popup → "Go to Pay Run"
✓
Press "Payment File" → "Download ABA File" and save locally
NAB — Transfer Funds
✓
Open the NAB bank account
✓
Press "Transfer & Pay" → "Multiple Funds Transfer"
✓
Select "Choose File" next to "By importing a Direct Entry file"
✓
Press "Next" → "Submit" — pay run complete ✅
